# GlowPulse

GlowPulse employs a real-time data processing engine to drive low-latency analytics on scalable clusters.

GlowPulse is built to be simple and practical, focusing on doing one thing well.

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/GlowPulse.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

GlowPulse is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
